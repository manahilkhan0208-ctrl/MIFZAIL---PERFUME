MIFZAIL PERFUME WEBSITE — START HERE

WHAT THIS IS
- A responsive, single-file storefront prototype for MIFZAIL, restyled in black, antique gold and warm beige, with the brand wordmark rendered in Arabic as ميفزايل.
- Includes an animated luxury homepage, product filters, a working cart, quantity controls, and a placeholder WhatsApp order flow.
- No Node.js, React, database, or paid software required for the first preview.
- Google Fonts and remote photography need internet access; the site itself opens locally.

HOW TO RUN IT ON WINDOWS
1. Download and extract MIFZAIL-perfume-website.zip.
2. Open the extracted folder.
3. Double-click index.html.
4. It should open in Microsoft Edge or Chrome.
5. Try the fragrance filters, add products to the bag, change quantities, and open the cart.

HOW TO EDIT
- Right-click index.html > Open with > Notepad (or use Visual Studio Code if you install it).
- Search for the products array in the script near the bottom to change names, prices, sizes and scent-note text. The Arabic brand spelling used for the logo and bottle labels is ميفزايل; the rest of the storefront copy remains English.
- Search for whatsappNumber to add your business WhatsApp number (digits only, including country code, e.g. 91XXXXXXXXXX).
- Replace the placeholder contact email and review all sample claims, prices, product details, shipping text and policies before publishing.

IMPORTANT
This is a front-end prototype, not a production e-commerce system. It does not securely take payments, store orders on a server, manage inventory, or collect newsletter subscriptions. Do not accept real payments based only on this prototype. Before launch, confirm actual product details, legal/business requirements, delivery/return policies, privacy terms and a secure checkout/payment provider.
